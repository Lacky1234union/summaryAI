# Summuraze

Локальный писатель саммари к созвонам, лекциям, встречам и семинарам.

Запись → транскрипт с таймкодами (STT локально, на CPU, без GPU) → структурированный документ
(DeepSeek по API или локальная модель — переключается флагом) → Markdown, который можно читать
вместо записи.

```
summuraze                                 # меню: записать / из файла / последние заметки / настройки
summuraze record --name "ЦОС лекция 3"    # микрофон + звук системы, по Ctrl+C — конспект
summuraze run lecture.mp4                 # из файла; --profile raw — транскрипт по блокам
summuraze web                             # браузер: записи, конспект, транскрипт и плеер по таймкодам
```

Заметка появляется в папке `SUMMURAZE_OUTPUT_DIR` (Obsidian) с таймкодами-ссылками на запись.
API ↔ локальная модель — значения `SUMMURAZE_LLM_BASE_URL` / `_MODEL` в `.env` или пункт меню
«Настройки».

Статус: **этап 2.5** — запись и меню; лекции с одним говорящим работают сквозным прогоном.

```bash
uv sync      # поставить зависимости
make help    # что вообще можно запустить
make lint    # ruff + mypy
make test    # быстрые тесты
```
