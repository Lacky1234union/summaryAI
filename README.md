# Summuraze

Локальный писатель саммари к созвонам, лекциям, встречам и семинарам.

Запись → транскрипт с таймкодами (STT локально, на CPU, без GPU) → структурированный документ
(DeepSeek по API или локальная модель — переключается флагом) → Markdown, который можно читать
вместо записи.

```
summuraze                                 # меню: записать / из файла / последние заметки / настройки
summuraze record --name "ЦОС лекция 3"    # микрофон + звук системы, по Ctrl+C — конспект
summuraze run lecture.mp4                 # из файла; --profile raw — транскрипт по блокам
summuraze web                             # браузер: записи, конспект, транскрипт и плеер по таймкодам
summuraze watch ~/Inbox                   # готовые файлы → очередь → заметки, по одному прогону
```

Заметка появляется в папке `SUMMURAZE_OUTPUT_DIR` (Obsidian) с таймкодами-ссылками на запись.
API ↔ локальная модель — значения `SUMMURAZE_LLM_BASE_URL` / `_MODEL` в `.env` или пункт меню
«Настройки».

Работают запись и меню, лекции с одним говорящим, длинные транскрипты, проверка утверждений
и веб-интерфейс. Качество STT и live-режим ещё требуют замеров на реальных записях.

В браузере можно править Markdown, скачать `.md`, скопировать его и записать в папку заметок
кнопкой «В Obsidian». **Сохранить правки** сохраняет ручную версию в SQLite отдельно от машинной;
повторный прогон публикует ручную версию и обновляет машинную отдельно. Проверка утверждений
относится к машинному конспекту. Две вкладки с устаревшей версией не перезаписывают друг друга.

Для автоматического импорта задай `SUMMURAZE_WATCH_DIR` в `.env` и запусти `summuraze web`
или `summuraze watch`. Без настройки папки автоматического импорта нет. При первом запуске
подхватываются и уже лежащие там файлы, без вложенных папок. Файл должен не менять размер и
mtime 10 секунд (`SUMMURAZE_WATCH_STABLE_SECONDS`); надёжнее копировать как `.part`, затем
переименовывать. Профиль и провайдер — `SUMMURAZE_WATCH_PROFILE` / `_PROVIDER` (`api` / `local`).
Перед автоматической отправкой API один раз разреши хост провайдера в терминале
(`summuraze watch`) или при запуске записи в вебе. `SUMMURAZE_LOCAL_ONLY=true`
продолжает запрещать внешние провайдеры, включая автоматические прогоны.

Очередь хранится в SQLite, ждёт завершения текущего прогона и восстанавливается после
перезапуска веба/наблюдателя. CLI и очередь используют общую блокировку тяжёлого конвейера.
Остановка наблюдателя сохраняет очередь; уже запущенный CLI-процесс продолжает работу.
Задачи, ожидающие обработки, отменяются в списке очереди; идущий прогон — на странице записи.
О готовности сообщает очередь в браузере и системное уведомление, если доступен `notify-send`.
Браузерные уведомления включаются кнопкой «Уведомлять о готовности» (нужна открытая страница
списка; доступ зависит от браузера и разрешений).

```bash
uv sync      # поставить зависимости
make help    # что вообще можно запустить
make lint    # ruff + mypy
make test    # быстрые тесты
```
